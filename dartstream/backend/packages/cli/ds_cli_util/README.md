# DartStream CLI utilities

This library provides project-directory, scaffolding, setup and YAML configuration helpers for DartStream. Import `package:ds_cli_util/ds_cli_utils.dart` to use its exported helpers, including `getProjectDir`, `createProject`, `saveProjectConfig` and `DSInitCommand`.

Version 0.0.2-pre.2 declares its path and YAML dependencies directly and is checked with Dart 3.13.4. The compatible Dart 3.12.2 minimum is retained.

This package has no standalone executable. The DartStream application command is provided by the `ds_dartstream` package.
